## 🏛️ Sobre mim

Sou **Igor Alves**, fundador da **OIKOS Imobiliária**, especializada em imóveis de alto padrão em **João Pessoa - PB**.

Meu trabalho é unir **atendimento próximo**, **curadoria de imóveis** e **tecnologia**. Uso ferramentas digitais para apresentar cada imóvel do jeito que ele merece: site, vídeos e conteúdo para redes sociais.
