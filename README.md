# Igor Alves — Corretor de Imóveis

Landing page profissional para **Igor Alves**, corretor de imóveis especializado em alto padrão no Rio de Janeiro.

## Sobre

Este projeto é uma landing page moderna e responsiva criada para apresentar os serviços do corretor Igor Alves (CRECI-RJ 123.456-F), com foco em imóveis de alto padrão nos bairros mais exclusivos do Rio de Janeiro, como Leblon, Ipanema, Barra da Tijuca, Gávea e Lagoa.

## Tecnologias

- **HTML5** — estrutura semântica
- **CSS3** — design moderno com variáveis CSS, animações e responsividade mobile-first
- **JavaScript (Vanilla)** — sem dependências externas
- **Google Fonts** — Inter + Playfair Display
- **Font Awesome 6** — ícones via CDN

## Funcionalidades

- Navbar fixa com efeito de scroll e menu hamburger para mobile
- Hero em tela cheia com gradiente, animações e cards flutuantes
- Barra de estatísticas com contador animado
- Grade de imóveis com filtros por categoria (Todos, Apartamentos, Casas, Terrenos)
- Seção Sobre com foto placeholder, certificações e diferenciais
- 4 cards de serviços com hover effects
- 3 depoimentos de clientes com avaliação por estrelas
- Seção de contato com informações e formulário funcional
- Footer completo com links de redes sociais
- Botão flutuante do WhatsApp com animação pulse
- Botão "Voltar ao topo"
- Animações de entrada via IntersectionObserver
- Efeito parallax sutil no hero

## Como usar

Basta abrir o arquivo `index.html` em qualquer navegador moderno. Não requer servidor ou dependências locais.
